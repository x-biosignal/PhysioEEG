# Transform raw features to the softmax design terms (internal)

Transform raw features to the softmax design terms (internal)

## Usage

``` r
.iclabel_terms(f)
```

## Arguments

- f:

  Named feature vector from
  [`.iclabel_features()`](https://x-biosignal.github.io/PhysioEEG/reference/dot-iclabel_features.md).

## Value

A named numeric vector of design terms matching the weight table.
